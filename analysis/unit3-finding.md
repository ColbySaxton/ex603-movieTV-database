What the dashboard reported:
The dashboard reported a spam withdrawal on a number of ratings whose status is withdrawn. A spam withdrawal can occur if there is a user who fakes a rating to withdraw a fee related to it.

This data shows that for all ratings that are withdrawn, there is not a reviewed at date and there are a number of withdrawal reasons. Those reasons can range from duplicate ratings, a policy violation or a spam is detected. The spam detected reason can occur when a fake ratings record is created which is detected by the lack of a reviewed at date.

The frozen payouts should be cancelled. If a rating is determined to be withdrawn due to spam, then the user should never recieve the payout and the payment should be cancelled. If it was an error, then the user can always submit another rating.
